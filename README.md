**One Road to Every Post Office** — one sentence, 155 characters, explaining the modern internet to a traveler from 1800, using only words they could already picture:

> Picture one road joining every post office, library, and town square on earth, so a letter sent at dawn is read by a stranger across the sea before supper.

`main.py` is its deterministic runner: it checks the sentence (1–200 characters, exactly one sentence, no word coined after 1800) and writes it to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
